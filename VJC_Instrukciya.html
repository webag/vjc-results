Инструкция по наполнению сайта VOLNOVA

Где на сайте volnovajc.ru берётся каждый блок и как его поменять в админке 1С-Битрикс. Разделы идут в порядке работы: сначала доступ и сброс кеша, потом страницы сайта сверху вниз.

После любой правки в админке сбросьте кеш (раздел 2), иначе изменения могут появиться на сайте не сразу.

1Вход в админку

Админка сайта: Админка

  1. Откройте ссылку. Если браузер покажет системное окно «Требуется авторизация» — это защита сервера, введите логин и пароль доступа к серверу.
  2. На странице входа Битрикса введите логин и пароль администратора и нажмите «Войти».

Логины и пароли (доступ к серверу и администратор Битрикса) передаются отдельно, по защищённому каналу. Не пересылайте их в открытых чатах и письмах.

Весь контент сайта лежит в меню Контент (левая панель админки). Нужные разделы: Контент → Главная, Бренды, Atelier, Акции; Блог; Структура сайта → Меню, Контентные страницы, Посадочные страницы; Баннеры; Конфигуратор; Справочники.

2Сброс кеша

Сайт кеширует данные из админки. Чтобы правки появились сразу, сбросьте кеш в два шага.

2.1Кеш в админке

  1. Откройте Настройки → Настройки продукта → Автокеширование (или пункт «Автокеширование» в «Избранном» на рабочем столе).
  2. Перейдите на вкладку «Очистка файлов кеша».
  3. Выберите «Все» и нажмите «Начать».

Прямая ссылка: Админка · cache

2.2Кеш на сайте

  1. Откройте сайт volnovajc.ru под тем же браузером, где вы вошли в админку.
  2. Кликните правой кнопкой мыши по иконке пользователя в правом верхнем углу.
  3. Появится сообщение, что кеш сброшен на клиентской части. Обновите страницу.

3.1Как работает редактор блоков

Большинство разделов элемента — это конструктор блоков: внутри раздела лежат один или несколько блоков с полями.

  • Текстовые поля меняются прямо в форме; форматированный текст — во встроенном редакторе (жирный, ссылки, списки).
  • Картинка: кнопка «Загрузить» (или «Удалить» рядом с текущей) — выберите файл с компьютера.
  • Списки (кнопки, слайды, карточки): «Добавить» — новая строка, ↑↓ — перетащить, × — удалить.
  • «Добавить блок» добавляет ещё один блок того же типа (например, ещё один слайд-набор).
  • В конце нажмите «Сохранить» (внизу страницы) или «Применить», чтобы остаться в форме. Затем сбросьте кеш.

Юридический текст с ERID. В блоках с рекламой есть поле «Юридический текст». На сайте он открывается по иконке ✻ в углу баннера. ERID и данные рекламодателя указывайте здесь; в тексте можно поставить ссылку через кнопку «ссылка» в панели редактора.

3.2Первый экран «Ювелирный клуб»

Раздел Шапка, Блок 1:

  • Заголовок и подзаголовок — крупная надпись по центру.
  • Фон — фоновое изображение первого экрана.
  • Список кнопок — пары «текст кнопки / ссылка» (клуб, Only Lab, Crystalit, Tereya, Core Code).
  • Юридический текст — текст по иконке ✻.

Кнопка «войти» выводится сайтом автоматически, в админке её нет.

3.3«Смыслы, которые мы создаем»

Раздел О клубе, Блок 3: заголовок, «Описание слева», «Описание справа», «Изображение по центру» (фото), «Изображение подписи» (подпись-автограф), подпись, текст и ссылка кнопки «Читать о клубе».

В этом же разделе есть Блок 2 «О КЛУБЕ и ЕЛЕНЕ» — сейчас на сайте он не выводится.

3.4«Подборка недели»

Раздел Блок подборка: заголовок блока и список карточек. У каждой карточки — подпись, ссылка и картинка. Порядок меняется стрелками ↑↓, новая карточка — кнопкой «Добавить».

3.5Блоки брендов: Only Lab, Crystalit, Tereya, Corecode

Каждый блок бренда собирается из двух мест:

  1. Элемент «Главная» — оформление блока: теги над описанием (tag1–tag3, например «золото · платина · бриллианты»), описание, картинки (логотип, фото слева/справа/по центру). Only Lab — раздел «Блок с товарами», Crystalit — «Блок 444», Tereya — «Блок 653», Corecode — «Блок 783».
  2. Элемент бренда в Контент → Бренды — кнопка и товары:
    • Текст кнопки и Ссылка на каталог — кнопка «каталог …» под описанием;
    • Избранные товары для главной — карточки товаров в блоке.

Какой бренд подставить, определяет поле «Символьный код бренда» в блоке на главной (only-lab, crystalit, tereya, corecode) — по нему берутся кнопка и товары из элемента бренда.

Бренды: Админка · инфоблок 11

3.6Atelier

Раздел Блок 545: описание, текст и ссылка кнопки («перейти в ателье»), фон для компьютера, фон для мобильных, картинка по центру (логотип Atelier).

3.7«Свежий взгляд»

Нижний раздел Блок с товарами элемента «Главная»:

  • Интро — мелкая надпись над заголовком;
  • Заголовок — «Свежий взгляд»;
  • Товары — выберите товары из каталога (начните вводить название и выберите из подсказки).

3.8Слайдеры «Подарочная карта» и «Комплекты на зиму»

Раздел Центральный слайдер. Внутри два блока «Блок 4 · Слайдер»: первый выводится после Crystalit, второй — после Corecode. В каждом — список слайдов; у слайда заголовок, ссылка, текст кнопки, описание, юридический текст и фон («Загрузить фон»).

3.9«Журнал · Редакторская подборка»

Статьи для этого блока берутся из Блога: Контент → Блог → Контент. На главную попадают статьи, у которых отмечено свойство «Рекомендуемая статья» = «Да». Порядок вывода — по полю «Сортировка» (меньше — выше).

Чтобы добавить статью на главную:

  1. Откройте статью в Блог → Контент (или создайте новую).
  2. На вкладке «Параметры» в свойстве «Рекомендуемая статья» выберите «Да».
  3. При необходимости поменяйте «Сортировку», чтобы поставить статью раньше или позже.
  4. Сохраните и сбросьте кеш.

Чтобы убрать статью с главной — снимите отметку «Рекомендуемая статья». Сейчас отмечено 6 статей.

4Конструктор украшений

Конструктор на сайте: volnovajc.ru/constructor. Покупатель проходит шаги мастера (тип украшения → цвет → форма камня → каратность → оправа → размер → гравировка → цепочка → срок) и получает собранное украшение с ценой и артикулом.

Все настройки конструктора — в группе инфоблоков Конфигуратор (левое меню Контент → Конфигуратор).

Список инфоблоков: Админка · iblock_admin

Символьные коды не меняйте. Сайт связывает шаги и варианты между собой по полю «Символьный код» (CODE). Меняйте названия, тексты, картинки и активность; новые варианты добавляйте копированием существующего.

4.1Общие правила

  • Показать или скрыть вариант — галочка «Активность» в элементе. Неактивные варианты на сайте не выводятся.
  • Порядок вариантов на шаге — поле «Сортировка» (меньше — левее/выше).
  • Название — короткая подпись в селекторе; Длинное название — текст в итоговом описании и в карточке собранного товара.
  • Код для артикула — кусочек артикула собранного изделия; итоговый артикул склеивается из кодов всех выбранных вариантов.
  • Привязки («к типу украшения», «к цвету», «к форме», «к каратности») задают, на каком сочетании выборов вариант появляется и какую картинку показывать.
  • После изменений сбросьте кеш (раздел 2) и пройдите конструктор на сайте до конца.

4.3Типы украшения (ID 27)

Первый шаг: что собирает покупатель. Сейчас включены Кольцо и Пусета одиночная (добавлена 30.09); «Пусеты» и «Подвеска» заведены, но выключены.

  • Длинное название, Название для товара — как украшение называется в итоге и в корзине.
  • Код для артикула.
  • Привязка к шагам — какие шаги мастера показывать для этого типа (выделите нужные с Ctrl). Например, у кольца шаг «Цепочка» не выбран — поэтому его нет в мастере.
  • Картинка для анонса — маленькая картинка в селекторе справа; Детальная картинка / Фото не собранного товара — большое изображение слева.
  • Текстовый оверлей для десктопа — картинка-подпись поверх изображения на компьютере.

Типы украшения: Админка · инфоблок 27

4.4Цвета (ID 28)

Цвет металла (белое, жёлтое, красное золото).

  • Привязка к типу украшения — для какого типа доступен цвет (картинки у разных типов разные).
  • Изображение основы украшения — шинка без камня и корзинки. Это подложка, поверх которой на следующих шагах накладываются камень и оправа.

Цвета: Админка · инфоблок 28

4.5Формы бриллиантов (ID 29)

  • Детальная картинка — изображение камня, которое накладывается поверх основы с шага «Цвет».
  • Подпись в правый верхний угол — картинка-подпись из макета (это файл, а не текст).
  • Изображение сравнения каратности — галерея для окна «на руке».

Формы бриллиантов: Админка · инфоблок 29

4.6Каратность бриллиантов (ID 30)

  • Привязка к форме бриллианта — каратность зависит от формы камня (выбирается символьный код формы).
  • Детальная картинка — камень с корзинкой без шинки; ложится в окно просмотра поверх шинки с шага «Цвет».

Каратность: Админка · инфоблок 30

4.7Оправы (ID 31)

Самый «насыщенный» шаг: оправа собирает вместе цвет, форму и каратность.

  • Код для артикула (корзинка) и (шинка).
  • Привязка к цвету, к форме, к каратности — вариант оправы заводится под каждое сочетание, потому что фотографии разные.
  • Фото собранного товара — с этим изображением собранное украшение попадает в корзину и в личный кабинет.
  • Галерея — фотографии для всплывающей галереи.

Картинки оправы — на вкладке «Галлерея» элемента: картинка для анонса, фото собранного товара и галерея (можно перетащить несколько файлов).

Оправы: Админка · инфоблок 31

4.8Размеры, гравировки, цепочка (ID 32, 33, 34)

Простые справочники: Название, Длинное название, Код для артикула; у гравировки и цепочки ещё Цена (доплата). Картинок нет.

Сверьте размеры с таблицей размеров: в справочнике есть элемент «14» с кодом артикула «15».

  • Размеры: Админка · инфоблок 32
  • Гравировки: Админка · инфоблок 33
  • Цепочка: Админка · инфоблок 34

4.9Сроки выполнения (ID 35)

Последний шаг: выгодный / стандарт / срочный.

  • Подсказка 1 и Подсказка 2 — тексты под вариантом (как в макете).
  • Множитель цены — на сколько умножается стоимость при выборе срока. Сейчас: выгодный (до 1 месяца) — 1, стандарт (до 2 недель) — 1.15 (+15 %), срочный (до 1 суток) — 1.3 (+30 %). Дробную часть пишите через точку.

Сроки: Админка · инфоблок 35

4.10Собранные украшения и Медиа (ID 40, 42)

  • Собранные украшения — сюда автоматически сохраняются украшения, собранные покупателями (пользователь, артикул, выбранные параметры, итоговая цена). Вручную здесь ничего править не нужно.
  • Медиа — общая галерея изображений конструктора.

В каждом пункте меню верхнего уровня есть служебное поле символьный код (catalog, client, about, networking, main, brend и т. п.). По нему сайт понимает, куда выводить группу. Коды не меняйте: меняйте названия, ссылки и порядок.

6.1Шапка сайта

Строка меню под логотипом — это пункты верхнего уровня поля Шапка, по порядку: у каждого название, символьный код и ссылка. Исключение — пункты с кодами catalog и client:

  • catalog («каталог») — не ссылка, а кнопка, которая раскрывает мега-меню. Колонки мега-меню — это его подгруппы («бренды», «Коллекции», «Виды украшений», «тренды», «создай своё»): у подгруппы есть заголовок и список пунктов «название — ссылка».
  • client («клиентам») — в строке меню на компьютере сейчас не выводится; его подгруппы используются только в мобильном меню, в разделе «Клиентам».

В названии можно использовать тег <span>…</span> — так сделана серая подпись после названия бренда («Only Lab <span>выращенные камни</span>»).

Ссылка «Подарочный сертификат» в последней колонке мега-меню зашита в вёрстке и в админке не редактируется.

Как добавить пункт в строку меню: в конце поля «Шапка» нажмите «Добавить», заполните название, придумайте латинский символьный код (например, sale), укажите ссылку и стрелками ↑↓ поставьте пункт на нужное место. Сохраните и сбросьте кеш.

6.2Подвал

Колонки подвала — группы поля Подвал по порядку: «КАТАЛОГ» (catalog), «Бренды» (brend), «Клиентам» (client), «О нас» (about). Группа «Мы в соц сетях» (networking) выводится не отдельной колонкой, а под колонкой «Клиентам».

7.6«Профиль»: уведомления

В ленте два вида уведомлений:

  1. Системные — о заказах, оплате, начислении карат. Создаются автоматически, в админке их заводить не нужно.
  2. Рассылочные — анонсы акций, гайды, советы по уходу. Их заводят в Справочники → Уведомления.

Поля уведомления:

  • Название и текст — заголовок и текст уведомления;
  • Тип уведомления — «акция», «скидка», «гайд» или «уход за украшениями»: от него зависит вкладка-фильтр в ленте («акции и скидки», «гайды», «уход за украшениями»);
  • Уровни лояльности — кому показывать (пусто — всем);
  • Подпись кнопки и Ссылка кнопки — кнопка под уведомлением («в каталог»).

7.9Вход, регистрация и удаление аккаунта

Войти на сайт можно тремя способами: по номеру телефона, через VK ID и через Яндекс ID. Отдельной регистрации нет — аккаунт создаётся при первом входе.

  • По телефону. Покупатель вводит номер и ставит согласие на обработку данных, нажимает «запросить код». Затем вводит код из СМС.
  • VK ID / Яндекс ID. Открывается окно сервиса, где покупатель разрешает передать свои данные.
  • После первого входа любым способом сайт предлагает заполнить личные данные (имя, фамилия, email, дата рождения), затем переводит в личный кабинет.
  • Один телефон — один аккаунт. Если номер телефона уже есть у какого-то покупателя, вход выполняется в его аккаунт, через какой бы сервис покупатель ни входил.
